# Ferramentas opcionais

- [Commit-reveal e aleatoriedade coletiva](randomness.md): desenho acordado.
- [Embaralhamento auditável e distribuição seletiva](shuffle.md): desenho conceitual, construção criptográfica pendente.

Ferramentas executam operações verificáveis sob governança da sala. A atividade define quando acioná-las, seus parâmetros e sanções. Não se presume que toda atividade precise de todas as ferramentas.
