# DAGP — Decentralized Activity Governance Protocol

**Autonomous activities. Collective decisions. No central authority.**

Status: 0.1.0-draft — experimental design, not a security-certified protocol.

DAGP coordinates autonomous peers without requiring a central governing authority or blockchain. Activities define membership requirements, rules, sanctions, state and resource semantics; DAGP provides discovery, constitution, deliberation, synchronization and optional cryptographic tools.
